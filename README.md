# soundFy

Музыкальная платформа в духе SoundCloud. На ней можно загружать свои треки, слушать их с волной, оставлять комментарии к конкретному моменту трека, собирать плейлисты и подписываться на авторов. Ещё одна часть — **синхронизация с музыкальными сервисами** (SoundCloud, ВК Музыка, Deezer, Apple Music/iTunes, Jamendo): вы подписываетесь на артиста, а soundFy сам находит его новые треки, добавляет их в ленту и присылает уведомления.

Для песен подтягивается информация с **Genius**: авторы, продюсеры, альбом, описание, сэмплы и текст через официальный виджет Genius. Треки во всех списках можно **фильтровать и сортировать по жанрам**.

Интерфейс сделан в **Material Design 3**: палитра генерируется из выбранного цвета официальной библиотекой Google, есть светлая и тёмная темы, стили палитры, уровни контраста и цвета из обложки играющего трека.

## Возможности

**Как в SoundCloud**
- Загрузка треков: drag-and-drop, обложка, жанр, описание. Волна строится в браузере, длительность и встроенная обложка берутся из тегов файла.
- Плеер внизу страницы: очередь, перемешивание, повтор, громкость, перемотка кликом по волне, горячая клавиша «пробел», управление из ОС (Media Session).
- Комментарии к моменту трека: аватары комментаторов видны прямо на волне.
- Лайки, плейлисты (публичные и приватные), история прослушиваний, подписки на пользователей.
- Лента подписок, «Обзор» с чартом за неделю, жанрами и свежими загрузками, поиск (в том числе по кириллице без учёта регистра).
- Уведомления о новых загрузках тех, на кого вы подписаны.

**Жанры**
- Жанры со всех сервисов приводятся к одному названию: «Hip-Hop/Rap» из iTunes, «Rap & Hip-Hop» из ВК и «рэп» из загрузки — это один жанр «Хип-хоп». Для Deezer жанр берётся из альбома, для Jamendo — из тегов трека.
- В каждом списке (лента, лайки, история, треки профиля, артист, плейлист, обзор) есть чипы-фильтры по жанрам со счётчиками и меню сортировки: «Сначала новые», «Популярные», «По жанрам» (с подзаголовками групп), «По названию». Выбор сохраняется в адресе страницы, так что отфильтрованным списком можно поделиться.
- В «Обзоре» есть раздел жанров в виде карточек.

**Genius**
- На странице трека в карточке информации появляются авторы, продюсеры, приглашённые артисты, альбом и дата выхода.
- Вкладка «О песне»: описание с Genius, полный список участников (включая звукорежиссёров и другие роли), связи с другими песнями (сэмплы, каверы, ремиксы, переводы), ссылки на YouTube и Spotify.
- Вкладка «Текст»: **официальный виджет Genius**. API Genius не отдаёт текст песен, поэтому soundFy не парсит и не хранит тексты. Браузер слушателя загружает виджет с genius.com в изолированном фрейме (`sandbox` без доступа к сайту soundFy). Рядом всегда есть ссылка на страницу песни.
- Песня подбирается автоматически по исполнителю и названию: «(feat. …)», «[Official Video]», «- Remastered» отбрасываются, а загрузки SoundCloud вида «Артист - Название» разбираются. Совпадение принимается, только если сходятся и название, и исполнитель. Если песня подобрана неверно, её можно выбрать вручную: для своих загрузок это может сделать автор, для треков из сервисов — любой слушатель.

**Оформление (Material Design 3)**
- Иконки Material Symbols (Rounded): в сборку попадают только используемые SVG, а для выбранных состояний есть заполненные варианты.
- Navigation rail на широких экранах и нижняя навигационная панель на телефонах, top app bar со строкой поиска, плавающий плеер с морфингом кнопки воспроизведения.
- Компоненты MD3: кнопки (filled, tonal, outlined, text, elevated), FAB, чипы, сегментированные кнопки, вкладки, текстовые поля с плавающей подписью, переключатели, диалоги, меню, снекбары, слайдеры и индикаторы прогресса.
- Диалог «Оформление» (иконка палитры в шапке или пункт в меню аккаунта):
  - тема: светлая, тёмная или как в системе;
  - основной цвет: готовые варианты с превью палитры или любой свой;
  - стиль палитры: яркая, спокойная, выразительная, точная, радуга, монохром и другие варианты MD3;
  - контрастность: обычная, средняя или высокая;
  - **цвета из обложки**: палитра подстраивается под обложку играющего трека, как Material You под обои.
- Все цвета — токены `--md-sys-color-*`. Они пересчитываются на лету через `@material/material-color-utilities` и восстанавливаются до первой отрисовки, без вспышки.

**Синхронизация с сервисами**
- Поиск артиста в любом подключённом сервисе и подписка на него.
- При подписке сразу загружается каталог артиста, затем планировщик проверяет новинки (по умолчанию раз в час). Проверку можно запустить и вручную.
- Новые треки появляются в ленте с отметкой «новый релиз», а подписчики получают уведомление.
- Треки из сервисов можно лайкать, комментировать и добавлять в плейлисты наравне с загруженными.
- SoundCloud: вход через свой аккаунт, импорт лайков в плейлист и подписка разом на всех авторов, за которыми вы следите.
- ВК Музыка: импорт ваших аудиозаписей в отдельный плейлист.

| Сервис | Что даёт | Что нужно |
|---|---|---|
| **SoundCloud** | Полные треки, новые загрузки авторов, импорт лайков и подписок | Ключи приложения `SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET` (см. ниже) |
| **ВК Музыка** | Полные треки, новые релизы артистов, импорт своих аудиозаписей | Токен ВКонтакте с доступом к аудио (см. ниже) |
| **Deezer** | Новые альбомы и синглы, 30-секундные превью | Ничего, открытый API |
| **Apple Music / iTunes** | Свежие песни из каталога Apple, 30-секундные превью | Ничего, открытый API (`ITUNES_COUNTRY` — витрина) |
| **Genius** | Авторы, продюсеры, описание, связи песен, виджет с текстом | Client access token `GENIUS_ACCESS_TOKEN` с [genius.com/api-clients](https://genius.com/api-clients) |
| **Jamendo** | Полные треки независимых артистов под лицензией CC | Бесплатный `JAMENDO_CLIENT_ID` с [devportal.jamendo.com](https://devportal.jamendo.com/) |

## Быстрый старт

Нужен Node.js 20.19+ (рекомендуется 22).

```bash
npm install
cp .env.example .env      # по желанию: Jamendo, общий токен VK, интервал синхронизации
npm run dev
```

- Фронтенд: http://localhost:5173
- API: http://localhost:4000. Vite проксирует к нему `/api` и `/media`.

База SQLite и загруженные файлы лежат в `./data` (путь меняется через `DATA_DIR`).

### Production

```bash
npm run build
npm start                 # http://localhost:4000 — API и собранный фронтенд на одном порту
```

Или в Docker:

```bash
docker compose up -d --build   # данные хранятся в томе soundfy-data
```

## Подключение SoundCloud

soundFy работает с **официальным API SoundCloud**.

1. Зарегистрируйте приложение на [soundcloud.com/you/apps](https://soundcloud.com/you/apps). Новые приложения SoundCloud может одобрять вручную.
2. Укажите redirect URI: `<адрес сайта>/api/services/soundcloud/oauth/callback`. Для разработки это `http://localhost:5173/api/services/soundcloud/oauth/callback`.
3. Пропишите в `.env` переменные `SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET`. В production также задайте `PUBLIC_URL`, чтобы redirect URI совпадал с зарегистрированным.

Что после этого работает:
- **Без входа пользователя:** поиск авторов, подписка на них и проверка новых загрузок. Для этого используется токен приложения (client credentials). SoundCloud ограничивает, как часто можно запрашивать новые токены, поэтому токен хранится в базе и переживает перезапуски сервера.
- **Воспроизведение:** сервер запрашивает у SoundCloud `/tracks/:id/streams` и отдаёт браузеру подписанную ссылку на CDN. Для треков Go+ доступно только превью.
- **Кнопка «Войти через SoundCloud»** на странице «Сервисы» (OAuth 2.1 с PKCE). После входа можно импортировать свои лайки в плейлист «SoundCloud: лайки» и подписаться на всех авторов, за которыми вы следите. Каталоги этих авторов загружаются в фоне. Токен пользователя обновляется автоматически по refresh token.

## Подключение ВК Музыки

Аудио-методы VK API (`audio.*`) **закрыты для сторонних приложений**. ВКонтакте отвечает на них только по токенам своих официальных клиентов (например, Kate Mobile) с правами `audio` и `offline`, причём User-Agent запроса должен совпадать с этим клиентом. Поэтому:

1. Получите access_token такого клиента для своего аккаунта.
2. Откройте в soundFy страницу **«Сервисы»** и вставьте в карточку «VK Музыка» сам токен или всю ссылку вида `https://oauth.vk.com/blank.html#access_token=…`. Токен извлечётся из неё сам.
3. soundFy проверит токен (`users.get` и пробный `audio.get`) и подключит аккаунт. После этого доступны поиск артистов ВК, подписка на них и импорт ваших аудиозаписей.

Подробности:
- Если ни у одного пользователя нет своего токена, для фоновой синхронизации используется общий токен сервера `VK_ACCESS_TOKEN`. User-Agent задаётся в `VK_USER_AGENT`.
- Ссылки на аудио ВК привязаны к клиенту, который их запросил, поэтому сервер soundFy сам скачивает поток и передаёт его в браузер, поддерживая перемотку (Range-запросы). Для этого используется токен слушателя. Если ВК отдаёт HLS (`.m3u8`), плеер воспроизводит его через hls.js.
- При поиске артистов используется `audio.searchArtists` и `audio.getAudiosByArtist`. Если токену эти методы недоступны, soundFy ищет треки через `audio.search` по имени исполнителя.
- **Важно:** это неофициальный способ доступа. ВКонтакте может в любой момент ограничить его, потребовать капчу или счесть нарушением правил. Токены хранятся в базе soundFy в открытом виде. Разворачивайте сервер только там, где доверяете его администратору, и никому не передавайте свой токен.

## Как работает синхронизация

```
Пользователь ──подписка──▶ external_artists ◀── SyncService ──▶ MusicProvider (soundcloud | vk | deezer | itunes | jamendo)
                                │                    │
                                ▼                    ▼
                         subscriptions         tracks (source, external_id) ──▶ notifications ──▶ лента и колокольчик
```

1. При подписке артист сохраняется в `external_artists`, и сразу запускается его первая синхронизация. Она импортирует последние треки без уведомлений, чтобы старый каталог не засыпал колокольчик.
2. `SyncService` по расписанию (`SYNC_INTERVAL_MINUTES`) обходит всех артистов, у которых есть подписчики. У провайдера запрашиваются свежие треки, и в базу добавляются только те, которых там ещё нет (уникальность по `(source, external_id)`). У уже известных треков обновляется ссылка на поток.
3. Треки, найденные после первой синхронизации и вышедшие не раньше чем 30 дней назад, рассылаются подписчикам как уведомления `new_release`.
4. Ошибки сервиса (неверный токен, капча, сеть) сохраняются у артиста и видны на странице «Сервисы». Остальные артисты при этом продолжают синхронизироваться.
5. При воспроизведении ссылка на поток запрашивается заново и кешируется на 10 минут: у Deezer и ВК ссылки подписаны и истекают.

### Как добавить новый сервис

Реализуйте интерфейс `MusicProvider` (`server/src/providers/types.ts`): `searchArtists`, `getArtistTracks`, `resolveStream`. По желанию добавьте подключение аккаунта (`connectMode: 'token'` с `verifyToken` или `'oauth'` с объектом `oauth`), `getUserLibrary` и `getUserFollowings`. Затем зарегистрируйте провайдер в `createProviders` (`server/src/providers/index.ts`) и добавьте цвет и название в `client/src/lib/services.ts`. Всё остальное (подписки, лента, уведомления, плеер) заработает без изменений.

### Основные эндпоинты API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | Регистрация и вход (JWT) |
| GET | `/api/feed?type=all\|releases\|uploads` | Лента подписок |
| GET | `/api/discover`, `/api/search?q=` | Обзор и поиск |
| POST | `/api/tracks` (multipart `audio`, `cover`) | Загрузка трека |
| GET | `/api/tracks/:id/source`, `/api/tracks/:id/stream` | Как воспроизводить трек и сам поток (Range) |
| POST/DELETE | `/api/tracks/:id/like`, `/api/tracks/:id/comments` | Лайки и комментарии |
| GET | `/api/services` | Сервисы и их статус для пользователя |
| POST/DELETE | `/api/services/:id/connect` | Подключение аккаунта по токену (ВК) |
| POST, GET | `/api/services/:id/oauth/start`, `/api/services/:id/oauth/callback` | Вход через сервис по OAuth (SoundCloud) |
| GET | `/api/services/:id/artists?q=` | Поиск артиста в сервисе |
| POST | `/api/services/:id/import` | Импорт своей библиотеки в плейлист |
| POST | `/api/services/:id/import-followings` | Подписка на всех авторов, за которыми вы следите в сервисе |
| GET/POST/DELETE | `/api/subscriptions` | Подписки на артистов |
| POST | `/api/sync`, `/api/artists/:id/sync` | Проверить новинки сейчас |
| GET | `/api/me/notifications` | Уведомления о релизах и загрузках |
| GET | `/api/genres?scope=…` | Жанры списка со счётчиками (`all`, `feed:all`, `likes:<user>`, `uploads:<user>`, `history`, `artist:<id>`) |
| GET, PUT | `/api/tracks/:id/genius` | Информация о песне с Genius; ручная привязка (`{ geniusId }` или `null`) |
| GET | `/api/genius/search?q=` | Поиск песни на Genius для ручной привязки |

Все списки треков принимают `?genre=<жанр>` (`-` — без жанра) и `?sort=new|popular|trending|genre|title`.

## Чего пока нет

- Ограничения частоты запросов на вход и поиск и шифрования токенов сервисов в базе. Стоит добавить перед публичным запуском.
- Перекодирования загрузок: файлы отдаются как есть, поэтому формат должен поддерживаться браузером (MP3, M4A, OGG, WAV, FLAC).
- Яндекс Музыки и Spotify: у них нет открытого способа получать потоки, но провайдер можно добавить по образцу существующих.
- Неофициального SoundCloud API (`api-v2` с client_id с сайта): используется только официальный API, поэтому нужны ключи приложения.
