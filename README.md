# MixOn

Музыкальная платформа в духе SoundCloud. На ней можно загружать свои треки, слушать их с волной, оставлять комментарии к конкретному моменту трека, собирать плейлисты и подписываться на авторов. Ещё одна часть — **синхронизация с музыкальными сервисами** (SoundCloud, ВК Музыка, YouTube Music, Deezer, Apple Music/iTunes, Jamendo): вы подписываетесь на артиста, а MixOn сам находит его новые треки, добавляет их в ленту и присылает уведомления.

У песен есть **синхронизированный текст** из открытой базы LRCLIB: текущая строка подсвечивается во время воспроизведения. С **Genius** подтягиваются авторы, продюсеры, альбом, описание и сэмплы. Треки во всех списках можно **фильтровать и сортировать по жанрам**, а открытые плейлисты Spotify, Deezer, SoundCloud и YouTube — **переносить по ссылке** без входа в эти сервисы.

Интерфейс сделан в **Material Design 3**: палитра генерируется из выбранного цвета официальной библиотекой Google, есть светлая и тёмная темы, стили палитры, уровни контраста и цвета из обложки играющего трека.

## Возможности

**Как в SoundCloud**
- Загрузка треков: drag-and-drop, обложка, жанр, описание. Волна строится в браузере, длительность и встроенная обложка берутся из тегов файла.
- Плеер внизу страницы: очередь, перемешивание, повтор, громкость, перемотка кликом по волне, горячая клавиша «пробел», управление из ОС (Media Session). На телефоне трек перематывается касанием или перетаскиванием по полоске внизу мини-плеера.
- **Полноэкранный плеер**, как в Spotify: нажатие на мини-плеер (на компьютере — на обложку или кнопку «Развернуть») открывает большую обложку, перемотку, все кнопки, очередь, скачивание и переход к тексту песни. Кнопка «Назад» на телефоне и Esc сворачивают его. У треков YouTube на месте обложки стоит окно плеера YouTube.
- У 30-секундных превью Deezer и Apple Music под треком написано «30-секундный отрывок», а в плеере — предупреждение.
- Комментарии к моменту трека: аватары комментаторов видны прямо на волне.
- Лайки, плейлисты (публичные и приватные), история прослушиваний, подписки на пользователей.
- Лента подписок, «Обзор» с чартом за неделю, жанрами и свежими загрузками, поиск (в том числе по кириллице без учёта регистра).
- Уведомления о новых загрузках тех, на кого вы подписаны.

**Жанры**
- Жанры со всех сервисов приводятся к одному названию: «Hip-Hop/Rap» из iTunes, «Rap & Hip-Hop» из ВК и «рэп» из загрузки — это один жанр «Хип-хоп». Для Deezer жанр берётся из альбома, для Jamendo — из тегов трека.
- В каждом списке (лента, лайки, история, треки профиля, артист, плейлист, обзор) есть чипы-фильтры по жанрам со счётчиками и меню сортировки: «Сначала новые», «Популярные», «По жанрам» (с подзаголовками групп), «По названию». Выбор сохраняется в адресе страницы, так что отфильтрованным списком можно поделиться.
- В «Обзоре» есть раздел жанров в виде карточек.

**Тексты песен**
- Вкладка «Текст» на странице трека. Текст ищется в [LRCLIB](https://lrclib.net), открытой базе синхронизированных текстов, которой не нужны ключи. Сначала идёт точный поиск по исполнителю, названию, альбому и длительности (если альбом не совпал, ещё раз без него), затем обычный поиск, который также находит синхронизированную версию, когда точный поиск вернул только текст без времени. Совпадение из поиска принимается, только если сходятся название и исполнитель, а длительность отличается не больше чем на 4 секунды. Запросы к LRCLIB идут по одному с паузой, как просят его авторы.
- Синхронизированный текст (LRC) следует за плеером: текущая строка подсвечивается, блок с текстом сам прокручивается к ней (но не мешает, если вы листаете его сами), а клик по строке перематывает трек на неё. У 30-секундных превью строки показываются без подсветки, потому что фрагмент начинается с середины песни.
- Для своих загрузок и треков SoundCloud название вида «Исполнитель - Песня» разбирается так же, как для Genius.
- Если синхронизированного текста нет, показывается обычный. Инструментальные треки отмечаются отдельно. Если в LRCLIB ничего нет, но настроен Genius, открывается официальный виджет Genius.
- Ответы LRCLIB кешируются в базе: найденный текст на 30 дней, отсутствие текста на 3 дня. Если LRCLIB недоступен, отдаётся устаревшая копия из кеша. `LRCLIB_URL=off` отключает поиск, а адрес своего зеркала LRCLIB можно указать в той же переменной.

**Genius**
- На странице трека в карточке информации появляются авторы, продюсеры, приглашённые артисты, альбом и дата выхода.
- Вкладка «О песне»: описание с Genius, полный список участников (включая звукорежиссёров и другие роли), связи с другими песнями (сэмплы, каверы, ремиксы, переводы), ссылки на YouTube и Spotify.
- Если текста нет в LRCLIB, во вкладке «Текст» показывается **официальный виджет Genius**. API Genius не отдаёт текст песен, поэтому MixOn не парсит и не хранит тексты с Genius. Браузер слушателя загружает виджет с genius.com в изолированном фрейме (`sandbox` без доступа к сайту MixOn). Рядом всегда есть ссылка на страницу песни.
- Сведения с Genius загружаются сразу при открытии страницы трека: над вкладками появляется карточка песни с началом описания и кнопкой «О песне, авторы и сэмплы».
- **Страница артиста:** при открытии MixOn находит артиста на Genius по имени (в том числе в написании вида «Кино (Kino)») и показывает фото, биографию, другие имена, число подписчиков на Genius, популярные песни и ссылки на Genius, Instagram, X и Facebook. Если у сервиса нет фото артиста, берётся фото с Genius. Найденный артист и его данные кешируются; если артиста нет на Genius, поиск повторяется через 3 дня.
- Песня подбирается автоматически по исполнителю и названию: «(feat. …)», «[Official Video]», «- Remastered» отбрасываются, а загрузки SoundCloud вида «Артист - Название» разбираются. Совпадение принимается, только если сходятся и название, и исполнитель. Если песня подобрана неверно, её можно выбрать вручную: для своих загрузок это может сделать автор, для треков из сервисов — любой слушатель.

**Оформление (Material Design 3)**
- Иконки Material Symbols (Rounded): в сборку попадают только используемые SVG, а для выбранных состояний есть заполненные варианты.
- Navigation rail на широких экранах и нижняя навигационная панель на телефонах, top app bar со строкой поиска, плавающий плеер с морфингом кнопки воспроизведения.
- Компоненты MD3: кнопки (filled, tonal, outlined, text, elevated), FAB, чипы, сегментированные кнопки, вкладки, текстовые поля с плавающей подписью, переключатели, диалоги, меню, снекбары, слайдеры и индикаторы прогресса.
- Диалог «Оформление» (иконка палитры в шапке или пункт в меню аккаунта):
  - тема: светлая, тёмная или как в системе;
  - основной цвет: готовые варианты с превью палитры или любой свой;
  - стиль палитры: яркая, спокойная, выразительная, точная, радуга, монохром и другие варианты MD3;
  - контрастность: обычная, средняя или высокая;
  - **цвета из обложки**: палитра подстраивается под обложку играющего трека, как Material You под обои.
- Все цвета — токены `--md-sys-color-*`. Они пересчитываются на лету через `@material/material-color-utilities` и восстанавливаются до первой отрисовки, без вспышки.

**Синхронизация с сервисами**
- Поиск артиста во всех подключённых сервисах сразу и подписка на него. Подписки собраны в «Медиатека → Артисты»: там можно проверить новинки или отписаться.
- При подписке сразу загружается каталог артиста, затем планировщик проверяет новинки (по умолчанию раз в час). Проверку можно запустить и вручную.
- Новые треки появляются в ленте с отметкой «новый релиз», а подписчики получают уведомление.
- Треки из сервисов можно лайкать, комментировать и добавлять в плейлисты наравне с загруженными.
- SoundCloud: вход через свой аккаунт, импорт лайков в плейлист и подписка разом на всех авторов, за которыми вы следите.
- ВК Музыка: импорт ваших аудиозаписей в отдельный плейлист.
- **Поиск по всем сервисам сразу:** введите в строке поиска имя артиста или название трека, и MixOn одновременно спросит все подключённые сервисы. Сверху будут артисты с кнопкой «Подписаться» (нажатие на артиста открывает его страницу с треками и без подписки), ниже — треки, которые можно сразу слушать, лайкать и добавлять в плейлисты; результаты можно отфильтровать по сервису. Найденные треки, которые вы не слушали и никуда не добавили, через три дня удаляются из базы, а в «Тренды» попадают только прослушанные.
- **Скачивание для офлайна:** кнопка «Скачать» у трека и у плейлиста сохраняет аудио на этом устройстве (в IndexedDB приложения), и плеер играет сохранённую копию без интернета. Скачанное собрано в «Медиатека → Скачанные». Сервер склеивает поток в один файл: прямые ссылки скачиваются как есть, HLS (ВК, часть SoundCloud) — по сегментам, с расшифровкой AES-128 и распаковкой MPEG-TS в MP3/AAC. Треки YouTube скачать нельзя: YouTube это запрещает. У Deezer и Apple Music сохраняется 30-секундное превью.
- **Импорт плейлиста по ссылке** (на главной или «Медиатека → Плейлисты»): вставьте ссылку на открытый плейлист или альбом Spotify (`open.spotify.com/playlist/…`, `open.spotify.com/album/…`, `spotify.link/…`), Deezer (`deezer.com/playlist/…`, `deezer.com/album/…`, `link.deezer.com/s/…`) плейлист SoundCloud (`soundcloud.com/автор/sets/…`, `on.soundcloud.com/…`) или YouTube (`music.youtube.com/playlist?list=…`, `youtube.com/playlist?list=…`, видео из плейлиста; нужен ключ YouTube). Получится приватный плейлист. Если импортировать ту же ссылку ещё раз, в него добавятся новые треки. Из Deezer берётся до 1000 треков, это 30-секундные превью. Сервер открывает только короткие ссылки самих сервисов, чтобы узнать, куда они ведут, и не ходит по произвольным адресам.
- **Плейлисты Spotify:** Spotify играет музыку только в своих приложениях, поэтому MixOn берёт со встраиваемой страницы плейлиста (`open.spotify.com/embed/…`, без ключей) только названия, исполнителей и длительности, а каждую песню ищет в подключённых сервисах: сначала полную версию (ВК Музыка, SoundCloud, Jamendo), иначе 30-секундное превью Deezer или Apple Music. Песня засчитывается, только если сходятся название, исполнитель и длительность (±20 секунд). YouTube при импорте не используется, чтобы не тратить его дневную квоту. В итоге видно, сколько песен нашлось, сколько из них превью и сколько не нашлось. Переносятся только треки, перечисленные на встраиваемой странице: у очень длинных плейлистов это может быть не весь список.

| Сервис | Что даёт | Что нужно |
|---|---|---|
| **SoundCloud** | Полные треки, новые загрузки авторов, плейлисты по ссылке, импорт лайков и подписок | Ничего: по умолчанию работает неофициальный режим без ключей. Для подписок на авторов и входа через SoundCloud — ключи приложения `SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET` (см. ниже) |
| **ВК Музыка** | Полные треки, новые релизы артистов, импорт своих аудиозаписей | Вход в аккаунт ВКонтакте по логину и паролю (см. ниже) |
| **Deezer** | Новые альбомы и синглы, плейлисты и альбомы по ссылке, 30-секундные превью | Ничего, открытый API |
| **Apple Music / iTunes** | Свежие песни из каталога Apple, 30-секундные превью | Ничего, открытый API (`ITUNES_COUNTRY` — витрина) |
| **LRCLIB** | Синхронизированные и обычные тексты песен | Ничего, включён по умолчанию (`LRCLIB_URL`) |
| **Genius** | Авторы, продюсеры, описание, связи песен, виджет с текстом | Ничего: встроен общий ключ MixOn. Свой client access token `GENIUS_ACCESS_TOKEN` с [genius.com/api-clients](https://genius.com/api-clients) можно указать вместо него |
| **Jamendo** | Полные треки независимых артистов под лицензией CC | Бесплатный `JAMENDO_CLIENT_ID` с [devportal.jamendo.com](https://devportal.jamendo.com/) |
| **YouTube Music** | Релизы и клипы артистов, плейлисты по ссылке; играют во встроенном плеере YouTube | Бесплатный ключ YouTube Data API v3 `YOUTUBE_API_KEY` (см. ниже) |

## Готовые приложения

Готовые файлы лежат в разделе **[Releases](https://github.com/qwixxys/MixOn/releases)**. Их собирает GitHub Actions (`.github/workflows/apps.yml`) при каждом изменении кода, а свежие сборки есть на вкладке **Actions**, в разделе Artifacts нужного запуска. Новый релиз публикуется сам, когда в `package.json` появляется новая версия (или при отправке тега вида `v0.2.0`).

| Файл | Что это |
|---|---|
| `MixOn-Setup-<версия>.exe` | Установщик для Windows 10/11 (x64) |
| `MixOn-<версия>-x86_64.AppImage` | Linux: `chmod +x` и запустить |
| `MixOn-<версия>.apk` | Android 7.0+ |

**Windows и Linux.** Приложение — это весь MixOn в одном окне: сервер работает внутри него, ничего настраивать не нужно. При первом запуске зарегистрируйте аккаунт.
- Данные (база, загруженные треки) хранятся в `%APPDATA%\MixOn` на Windows и `~/.config/MixOn` на Linux и не удаляются вместе с приложением.
- Ключи сервисов (SoundCloud, YouTube, Genius, Jamendo) вводятся прямо в приложении: меню **MixOn → Ключи сервисов** или страница «Сервисы», в карточке нужного сервиса. Там же пошагово написано, где взять каждый ключ. Ключи включают сервис сразу, без перезапуска. Для входа через SoundCloud укажите в настройках приложения SoundCloud redirect URI `http://127.0.0.1:4777/api/services/soundcloud/oauth/callback`.
- Установщик не подписан сертификатом, поэтому Windows SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае». SmartScreen перестаёт предупреждать только о файлах, подписанных сертификатом подписи кода (Code Signing) с накопленной репутацией; убрать предупреждение без сертификата нельзя. Если сертификат есть в виде `.pfx`, добавьте в Settings → Secrets → Actions секреты `WIN_CSC_LINK` (содержимое `.pfx` в base64) и `WIN_CSC_KEY_PASSWORD` — установщик будет подписываться при сборке. Сертификаты, выданные после июня 2023 года, хранятся на защищённом токене или в облаке (например, SSL.com eSigner, Azure Trusted Signing); для них подпись настраивается отдельно. Открытым проектам бесплатную подпись даёт SignPath Foundation. Каждый выпуск можно также отправить в Microsoft на проверку как ложное срабатывание: https://www.microsoft.com/wdsi/filesubmission.

**Android.** Приложение работает на телефоне само, компьютер не нужен: внутри APK тот же сервер MixOn, только база SQLite работает в WebAssembly (sql.js) и хранится на телефоне, а запросы к сервисам идут через сетевой клиент Android. Аккаунт создаётся сам при первом запуске.
- Есть: поиск по всем сервисам сразу, скачивание треков для прослушивания без интернета, прослушивание ВК Музыки, YouTube Music, Deezer, Apple Music, SoundCloud и Jamendo, подписки на артистов и новые релизы (проверяются раз в час, пока приложение открыто), вход в ВК по логину и паролю, импорт аудиозаписей ВК, лайки, плейлисты, тексты песен из LRCLIB, Genius, импорт плейлистов по ссылке.
- Ключи YouTube, Jamendo, а при желании свои ключи SoundCloud и Genius вводятся на странице «Сервисы» в карточке сервиса и хранятся на телефоне, вход в ВКонтакте по логину и паролю — в карточке ВК Музыки там же. Без ключей работают SoundCloud (неофициальный режим), Genius (встроенный ключ), Deezer, Apple Music, LRCLIB и импорт по ссылке.
- ВК отдаёт ссылку на аудио только тому, кто её запросил. Сервер MixOn поэтому пропускает звук через себя, а на телефоне и запрос, и воспроизведение идут с самого телефона: аудио ВК приложение загружает само, с тем же User-Agent, что и запросы к API (`VkAudioRelay.java`).
- Нет: загрузки своих треков, входа через SoundCloud для импорта лайков и подписок, общих аккаунтов. Для этого подключитесь к серверу.

**Подключение к серверу.** В меню профиля выберите **«Подключиться к серверу»**:
- **MixOn на компьютере:** в меню **MixOn → Подключить телефон** включите доступ из локальной сети. Приложение покажет адрес вида `http://192.168.1.10:4777`; введите его на телефоне, подключённом к той же Wi-Fi сети. Пока доступ выключен, сервер принимает подключения только с этого компьютера.
- **MixOn на сервере** (Docker, VPS): введите адрес сайта.

Пока выбран сервер, приложение открывает его при запуске; кнопка **«Музыка на телефоне, без сервера»** на экране подключения возвращает к музыке на телефоне. Данные на телефоне и на сервере не смешиваются. Ссылки на другие сайты открываются в браузере. Установка: разрешите установку из неизвестных источников. Ограничения: музыка играет в фоне, пока Android не выгрузит приложение из памяти, а кнопок управления в шторке уведомлений пока нет. Данные на телефоне удаляются вместе с приложением.

**Подпись APK.** С версии 0.6.5 собирается обычный (release) APK, без отладочного режима, на который проверка приложений Android (Play Protect) реагирует настороженнее. Без настройки он подписан общим ключом из репозитория (`mobile/android/app/debug.keystore`), тем же, что и прежние сборки: новые версии ставятся поверх и сохраняют данные. Если стоит версия 0.2.0, перед установкой новой удалите её один раз: она подписана другим ключом. Ключ из репозитория публичный, поэтому для своих сборок лучше подписывать собственным ключом: создайте его и добавьте в Settings → Secrets → Actions четыре секрета (переход на свой ключ потребует один раз переустановить приложение, данные на телефоне при этом удалятся):

```bash
keytool -genkeypair -v -keystore mixon.jks -alias mixon -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 mixon.jks   # → ANDROID_KEYSTORE_BASE64
```

`ANDROID_KEYSTORE_PASSWORD` и `ANDROID_KEY_PASSWORD` — пароли из `keytool`, `ANDROID_KEY_ALIAS` — `mixon`. Храните `mixon.jks` в надёжном месте: без него нельзя выпустить обновление, которое встанет поверх.

**Play Protect.** Приложение не из Google Play, поэтому Android может предложить проверить его или предупредить, что разработчик неизвестен: «Подробнее» → «Всё равно установить». Полностью предупреждение уходит только у приложений из Google Play или у проверенных Google разработчиков. Разработчик может оспорить предупреждение для своего приложения через форму Play Protect: https://support.google.com/googleplay/android-developer/contact/protectappeals.

## Ключи сервисов

Deezer, Apple Music, LRCLIB и импорт по ссылке работают без ключей, ВКонтакте каждый пользователь подключает своим токеном. SoundCloud по умолчанию работает в неофициальном режиме без ключей, а для **Genius** в MixOn встроен общий ключ: он есть в каждой сборке, поэтому публичен, и при большой нагрузке Genius может ограничивать по нему запросы — тогда укажите свой. Для **Jamendo** и **YouTube Music** нужны ключи API, которые выдают сами сервисы. Ключи можно ввести двумя способами:

- **В приложении:** страница «Сервисы», блок «Ключи API» в карточке сервиса. Его видит только владелец сервера — первый зарегистрированный аккаунт (в приложении для компьютера это вы). Там же пошаговые инструкции и адрес возврата для SoundCloud. Ключи хранятся в базе этого сервера и применяются сразу; в ответах сервера показываются только их последние символы.
- **В `.env`** (`SOUNDCLOUD_CLIENT_ID`, `SOUNDCLOUD_CLIENT_SECRET`, `GENIUS_ACCESS_TOKEN`, `JAMENDO_CLIENT_ID`, `YOUTUBE_API_KEY`, `SOUNDCLOUD_PUBLIC_CLIENT`). Значение из `.env` важнее и в приложении не меняется.

Не встраивайте ключи в сборки, которые выкладываете для других: из установщика их может достать любой.

## Подключение SoundCloud

MixOn работает с **официальным API SoundCloud**.

1. Зарегистрируйте приложение на [soundcloud.com/you/apps](https://soundcloud.com/you/apps). Новые приложения SoundCloud может одобрять вручную.
2. Укажите redirect URI: `<адрес сайта>/api/services/soundcloud/oauth/callback`. Для разработки это `http://localhost:5173/api/services/soundcloud/oauth/callback`.
3. Вставьте Client ID и Client Secret на странице «Сервисы» в карточке SoundCloud («Ключи API») или пропишите в `.env` переменные `SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET`. В production также задайте `PUBLIC_URL`, чтобы redirect URI совпадал с зарегистрированным.

Что после этого работает:
- **Без входа пользователя:** поиск авторов, подписка на них и проверка новых загрузок. Для этого используется токен приложения (client credentials). SoundCloud ограничивает, как часто можно запрашивать новые токены, поэтому токен хранится в базе и переживает перезапуски сервера.
- **Воспроизведение:** сервер запрашивает у SoundCloud `/tracks/:id/streams` и отдаёт браузеру подписанную ссылку на CDN. Для треков Go+ доступно только превью.
- **Кнопка «Войти через SoundCloud»** на странице «Сервисы» (OAuth 2.1 с PKCE). После входа можно импортировать свои лайки в плейлист «SoundCloud: лайки» и подписаться на всех авторов, за которыми вы следите. Каталоги этих авторов загружаются в фоне. Токен пользователя обновляется автоматически по refresh token.

### Режим без ключей (неофициальный)

Если ключей приложения нет, работает режим без ключей. Он включён по умолчанию; выключить его можно переключателем в карточке SoundCloud на странице «Сервисы» или `SOUNDCLOUD_PUBLIC_CLIENT=0` в `.env`. Тогда MixOn работает так же, как веб-плеер soundcloud.com: берёт публичный `client_id` из скриптов сайта и обращается к внутреннему API `api-v2.soundcloud.com`. Пользователям ничего вводить не нужно. Работают поиск авторов, полное прослушивание и импорт плейлистов по ссылке. Подписки на авторов SoundCloud в этом режиме ненадёжны (см. ниже), а вход через SoundCloud, импорт лайков и подписок не работают совсем.

- Звук: с 2026 года SoundCloud отдаёт почти всё как AAC через HLS, плеер воспроизводит его через hls.js. Треки с DRM (Widevine, FairPlay) пропускаются, у треков Go+ доступен только 30-секундный фрагмент. Подписанная ссылка на поток живёт примерно столько, сколько длится трек, поэтому сервер не держит её в кеше дольше.
- `client_id` хранится в базе и запрашивается заново раз в сутки или если SoundCloud его отклонил, но не чаще раза в 10 минут. Запросы идут не чаще двух в секунду. `client_id` отправляется только на `api-v2.soundcloud.com`.
- С 2026 года SoundCloud отвечает 403 на часть запросов, которые приходят не из браузера, прежде всего на список треков автора, по которому MixOn узнаёт о новых загрузках. MixOn не пытается обойти эту защиту: в таком случае у артиста в «Медиатека → Артисты» будет видна ошибка с объяснением, а для подписок на авторов SoundCloud нужны официальные ключи.
- **Это неофициальный способ.** SoundCloud прямо просит не использовать `api-v2` в сторонних приложениях. Режим может перестать работать в любой момент, если сайт изменится или SoundCloud заблокирует IP сервера, а его использование может нарушать правила SoundCloud. Поэтому на странице «Сервисы» у SoundCloud в этом режиме стоит предупреждение, а владелец сервера может выключить режим. Если ключи приложения заданы, всегда используется официальный API.

## Подключение YouTube Music

1. Откройте [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) в Google Cloud, войдите в аккаунт Google, создайте проект и нажмите **Enable**.
2. В [Credentials](https://console.cloud.google.com/apis/credentials) нажмите **Create credentials → API key** (не OAuth client ID; если спросят про данные — Public data) и вставьте ключ вида `AIza…` в карточку YouTube Music на странице «Сервисы» (или `YOUTUBE_API_KEY` в `.env`). Ограничение «Application restrictions» не ставьте: с ним ключ не будет работать из MixOn. Ограничить ключ только YouTube Data API v3 можно.

Ключ бесплатный, у него дневная квота: примерно 100 поисков артистов в день. Проверка новых релизов (2 единицы квоты на артиста) и импорт плейлистов (1 единица на 50 треков) почти её не тратят.

Как это работает:
- Поиск находит каналы артистов. Каналы вида «Артист - Topic» — это официальные релизы, которые YouTube Music собирает из каталогов лейблов; у их треков есть альбом и дата релиза.
- Из загрузок канала берутся музыкальные видео от 1 до 20 минут, которые разрешено встраивать: без Shorts, трансляций и длинных миксов.
- YouTube разрешает воспроизводить свои видео только в собственном плеере, видимом и не меньше 200×200 пикселей. Поэтому трек YouTube играет во встроенном плеере YouTube в небольшом окне в углу, а кнопки MixOn (пауза, перемотка, громкость, следующий трек) управляют им. Окно можно переместить наверх или вниз и закрыть. Слушать YouTube со скрытым плеером нельзя, поэтому при закрытии MixOn ищет ту же песню в сервисах с обычным аудио (ВК Музыка, SoundCloud, Jamendo: полная версия, то же название и исполнитель, длительность ±20 секунд) и продолжает с того же места без видео. Если такой версии нет, трек встаёт на паузу, а кнопка воспроизведения возвращает окно. Звук из видео не извлекается и не сохраняется, поэтому треки YouTube нельзя скачать. Если владелец запретил встраивание, трек не попадёт в ленту, а при попытке воспроизвести покажется понятная ошибка.

## Подключение ВК Музыки

Аудио-методы VK API (`audio.*`) **закрыты для сторонних приложений**. ВКонтакте отвечает на них только своим официальным приложениям с правами `audio` и `offline`, причём User-Agent запроса должен совпадать с приложением. Раньше MixOn представлялся Kate Mobile, но в сентябре 2026 ВКонтакте закрыл доступ и ему. Поэтому теперь MixOn входит в аккаунт **как официальное приложение «ВКонтакте для Android»** и его же User-Agent (`VK_USER_AGENT`):

1. Откройте в MixOn страницу **«Сервисы»**, карточку «VK Музыка», и введите телефон или почту и пароль от ВКонтакте.
2. Если включено подтверждение входа, ВКонтакте пришлёт код (SMS, звонок или приложение-аутентификатор) — введите его. Иногда ВКонтакте просит пройти проверку «я не робот»: в приложении MixOn для Android она открывается в отдельном окне, в обычном браузере этот способ входа её пройти не может.
3. Пароль уходит только во ВКонтакте (`oauth.vk.com/token`, «прямая авторизация») и не сохраняется. MixOn получает токен с доступом к аудио, проверяет его (`users.get` и пробный `audio.get`) и подключает аккаунт. После этого доступны поиск артистов ВК, подписка на них и импорт ваших аудиозаписей.

Подробности:
- Если ни у одного пользователя нет своего токена, для фоновой синхронизации используется общий токен сервера `VK_ACCESS_TOKEN`. User-Agent задаётся в `VK_USER_AGENT`.
- Ссылки на аудио ВК привязаны к клиенту, который их запросил, поэтому сервер MixOn сам скачивает поток и передаёт его в браузер, поддерживая перемотку (Range-запросы). Для этого используется токен слушателя. Если ВК отдаёт HLS (`.m3u8`), плеер воспроизводит его через hls.js.
- При поиске артистов используется `audio.searchArtists` и `audio.getAudiosByArtist`. Если токену эти методы недоступны, MixOn ищет треки через `audio.search` по имени исполнителя.
- **Важно:** это неофициальный способ доступа. ВКонтакте может в любой момент ограничить его, потребовать капчу, временно заблокировать аккаунт за необычный вход или счесть всё это нарушением правил. Токены хранятся в базе MixOn в открытом виде (пароль не хранится вовсе). Разворачивайте сервер только там, где доверяете его администратору, и никому не передавайте свой токен.

## Как работает синхронизация

```
Пользователь ──подписка──▶ external_artists ◀── SyncService ──▶ MusicProvider (soundcloud | vk | deezer | itunes | jamendo)
                                │                    │
                                ▼                    ▼
                         subscriptions         tracks (source, external_id) ──▶ notifications ──▶ лента и колокольчик
```

1. При подписке артист сохраняется в `external_artists`, и сразу запускается его первая синхронизация. Она импортирует последние треки без уведомлений, чтобы старый каталог не засыпал колокольчик.
2. `SyncService` по расписанию (`SYNC_INTERVAL_MINUTES`) обходит всех артистов, у которых есть подписчики. У провайдера запрашиваются свежие треки, и в базу добавляются только те, которых там ещё нет (уникальность по `(source, external_id)`). У уже известных треков обновляется ссылка на поток.
3. Треки, найденные после первой синхронизации и вышедшие не раньше чем 30 дней назад, рассылаются подписчикам как уведомления `new_release`.
4. Ошибки сервиса (неверный токен, капча, сеть) сохраняются у артиста и видны в «Медиатека → Артисты». Остальные артисты при этом продолжают синхронизироваться.
5. При воспроизведении ссылка на поток запрашивается заново и кешируется на 10 минут: у Deezer и ВК ссылки подписаны и истекают.

### Как добавить новый сервис

Реализуйте интерфейс `MusicProvider` (`server/src/providers/types.ts`): `searchArtists`, `getArtistTracks`, `resolveStream`. По желанию добавьте подключение аккаунта (`connectMode: 'token'` с `verifyToken` или `'oauth'` с объектом `oauth`), `getUserLibrary` и `getUserFollowings`. Затем зарегистрируйте провайдер в `createProviders` (`server/src/providers/index.ts`) и добавьте цвет и название в `client/src/lib/services.ts`. Всё остальное (подписки, лента, уведомления, плеер) заработает без изменений.

### Основные эндпоинты API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | Регистрация и вход (JWT) |
| GET | `/api/feed?type=all\|releases\|uploads` | Лента подписок |
| GET | `/api/discover`, `/api/search?q=` | Обзор и поиск |
| POST | `/api/tracks` (multipart `audio`, `cover`) | Загрузка трека |
| GET | `/api/tracks/:id/source`, `/api/tracks/:id/stream` | Как воспроизводить трек и сам поток (Range) |
| POST/DELETE | `/api/tracks/:id/like`, `/api/tracks/:id/comments` | Лайки и комментарии |
| GET | `/api/services` | Сервисы и их статус для пользователя |
| POST/DELETE | `/api/services/:id/connect` | Подключение аккаунта по токену (ВК) |
| POST, GET | `/api/services/:id/oauth/start`, `/api/services/:id/oauth/callback` | Вход через сервис по OAuth (SoundCloud) |
| GET | `/api/services/:id/artists?q=` | Поиск артиста в сервисе |
| GET | `/api/services/:id/search?q=` | Поиск по всему приложению в одном сервисе: артисты (с отметкой подписки) и треки, сохранённые в базу |
| POST | `/api/artists` (`{ provider, externalId, name }`) | Открыть страницу найденного артиста без подписки (каталог загружается, если его ещё нет) |
| GET | `/api/tracks/:id/audio-version` | Та же песня в сервисе с обычным аудио — для продолжения без видео YouTube |
| GET | `/api/tracks/:id/download` | Аудио трека одним файлом для офлайна (HLS собирается на сервере; YouTube — 403) |
| POST | `/api/services/:id/import` | Импорт своей библиотеки в плейлист |
| POST | `/api/import` (`{ url }`) | Импорт открытого плейлиста или альбома по ссылке в приватный плейлист; для Spotify песни ищутся в сервисах слушателя, в ответе есть `missing` и `previews` |
| POST | `/api/services/:id/import-followings` | Подписка на всех авторов, за которыми вы следите в сервисе |
| GET/POST/DELETE | `/api/subscriptions` | Подписки на артистов |
| POST | `/api/sync`, `/api/artists/:id/sync` | Проверить новинки сейчас |
| GET | `/api/me/notifications` | Уведомления о релизах и загрузках |
| GET | `/api/genres?scope=…` | Жанры списка со счётчиками (`all`, `feed:all`, `likes:<user>`, `uploads:<user>`, `history`, `artist:<id>`) |
| GET, PUT | `/api/tracks/:id/genius` | Информация о песне с Genius; ручная привязка (`{ geniusId }` или `null`) |
| GET | `/api/genius/search?q=` | Поиск песни на Genius для ручной привязки |
| GET | `/api/artists/:id/genius` | Артист с Genius для страницы артиста: биография, фото, ссылки, популярные песни |
| GET, PUT | `/api/settings/keys` | Ключи сервисов (только владелец сервера); значения не возвращаются, только маска |
| GET | `/api/tracks/:id/lyrics` | Текст песни из LRCLIB: строки с временем (`synced`), обычный текст (`plain`), признак инструментала |

Все списки треков принимают `?genre=<жанр>` (`-` — без жанра) и `?sort=new|popular|trending|genre|title`.

## Чего пока нет

- Ограничения частоты запросов на вход и поиск и шифрования токенов сервисов в базе. Стоит добавить перед публичным запуском.
- Перекодирования загрузок: файлы отдаются как есть, поэтому формат должен поддерживаться браузером (MP3, M4A, OGG, WAV, FLAC).
- Яндекс Музыки и Spotify: у них нет открытого способа получать потоки, но провайдер можно добавить по образцу существующих.
- Импорта по ссылке из ВК и Apple Music.
- Надёжного фонового воспроизведения YouTube: встроенный плеер YouTube может остановиться, когда приложение свёрнуто.
